# Abstraction Layers

Status: draft

ACES can be expressed across multiple abstraction layers.

| Layer | Purpose |
| --- | --- |
| L0 - Lived Reality | Direct human experience |
| L1 - Principles | Adaptive intuitions |
| L2 - Systems | Institutional dynamics |
| L3 - Structural | Topology and conductance |
| L4 - Formal | Equations and operators |
| L5 - Geometric | ACES-GA multivector substrate |

Layer discipline matters. A failure at one layer should not be hidden by fluency at another.
