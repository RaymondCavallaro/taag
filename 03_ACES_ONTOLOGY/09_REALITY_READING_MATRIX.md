# Reality Reading Matrix

Status: draft

The ACES reality reading matrix is a diagnostic state vector:

```text
R, Delta O, P, C, I, E_a, P_a, L, O_b, A_v
```

Where:

- `R`: reconstructability,
- `Delta O`: optionality,
- `P`: participation topology,
- `C`: concentration/capture pressure,
- `I`: interface/conductance topology,
- `E_a`: adaptive elasticity,
- `P_a`: adaptive plasticity,
- `L`: legitimacy,
- `O_b`: observability integrity,
- `A_v`: analysis viability.

This matrix should guide inquiry, not create false precision.
