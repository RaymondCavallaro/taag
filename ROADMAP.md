# Roadmap

Status: draft

## Current Milestone: v0.1 Adaptive Grammar Release

Goal: make ACES/TAAG coherent enough for external cognition.

v0.1 should allow a human or AI system to understand:

- what ACES/TAAG is,
- what it is for,
- what it is not for,
- what the core invariants are,
- how the diagnostic protocol works,
- how AI can use the framework carefully,
- how AI can misuse the framework,
- what a report should include,
- and what a grounded example looks like.

## v0.1 Priorities

- README as entry router.
- Status labels and contribution hygiene.
- Core compression and ontology overview.
- TAAG manual overview.
- Six-phase diagnostic protocol.
- AI reasoning and misuse protocols.
- Glossary seed.
- Case study template and at least one draft case.
- Build manifest for combined Markdown/PDF snapshots.

## v0.2 Priorities

- Expand core invariants into separate modules.
- Add question banks.
- Add report standard.
- Add 3-5 case studies.
- Add diagrams for topology, feedback, participation, and legitimacy loops.
- Add machine-readable schemas for diagnostic reports and state vectors.

## Long-Term Directions

- Public website or documentation portal.
- PDF release pipeline.
- AI reasoning pack releases.
- Benchmark suite.
- Diagnostic app.
- Simulator.
- Multi-agent adaptive governance tools.
- Deeper ACES-GA formalization.
