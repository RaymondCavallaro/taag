# Case Studies Overview

Status: draft

Back to start: [../README.md](../README.md)

Case studies ground ACES/TAAG in concrete systems.

Each case should test whether the framework improves analysis rather than merely decorating the system with terminology.

Recommended structure:

- system summary,
- analysis viability,
- key participants,
- flows and conductance,
- observability and metrics,
- reconstructability,
- optionality,
- participation integrity,
- capture pressures,
- intervention options,
- cautions and non-conclusions.
