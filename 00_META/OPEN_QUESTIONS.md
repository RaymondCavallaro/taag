# Open Questions

Status: draft

This file preserves unresolved questions without forcing premature closure.

## Framework Questions

- Which invariants are truly core, and which are derived?
- How should ACES/TAAG distinguish descriptive, normative, and epistemic claims in every analysis?
- What minimum evidence is required before a system can be meaningfully diagnosed?
- How should legitimacy be represented without collapsing it into popularity, legality, or efficiency?

## AI Questions

- How much of the framework should be loaded into an AI context at once?
- What prompt structures best preserve uncertainty and missing signals?
- How can AI outputs be made auditable by non-experts?

## Formal Questions

- Which ACES-GA concepts are operationally necessary?
- Can dimensional collapse be measured usefully without overclaiming precision?
- What would count as a falsifying or corrective case for a formal ACES claim?
